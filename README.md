Requirements
Node.js Engine: Installed on your computer to run the JavaScript code.
FFmpeg & 7-Zip: FFmpeg must be downloaded and extracted (using 7-Zip) to a known location (like C:\ffmpeg) so the bot can convert raw audio files into MP3s.
Structured Local Folder: A project directory containing your index.js script, installed node modules (npm install), and an automatically generated /recordings folder.
Private .env File: A file in your project folder holding your unique DISCORD_TOKEN configuration.
Message Content Intent: This specific toggle must be turned ON inside the Discord Developer Portal under your bot's settings so it can read text commands.
Bot Invite Permissions: An invitation link generated with View Channels, Send Messages, Connect, and Speak permissions checked.
Server Admin Rights: You need Manage Server or Administrator permissions in the target Discord server to successfully authorize and add the bot.
